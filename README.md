# 全球青年热议 · Global Trends

每日整理 **欧美** 和 **日韩** 年轻人在 X 上热议的话题。每个话题收录 3–5 条热帖，每条热帖附 3–5 条热评，并附带帖子里的图片、视频和 GIF。非中文内容全部提供中文翻译。

- 站点：https://zhbink.github.io/global-trends/
- 数据：`data/index.json`、`data/YYYY-MM-DD.json`
- 更新流程：见 [UPDATE.md](UPDATE.md)

站点是纯静态的（`index.html` + `static/`），没有构建步骤。数据只来自 X 接口。

关于数据的局限：X 无法按年龄筛选，“年轻人”是推断出来的；热度是关键词计数。
